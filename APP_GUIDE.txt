WHAT IS THIS APP?
-----------------
Ezer HRMS is a web-based Human Resource Management System built
for Indian companies. It is designed to manage the entire
employee lifecycle — from hiring to retirement — including
payroll, compliance with Indian labour laws (EPF, ESIC, PT, LWF),
attendance, letters, and reporting.

The app is built for large business groups that own multiple
companies (e.g. "Sharma Group" owns Sharma Sons, Sharma Petro,
Sharma Rail, etc.). All companies are managed from one platform.

================================================================
TECHNOLOGY STACK (How it is built)
================================================================
- Framework:     Next.js 16 (React-based web framework)
- Language:      TypeScript
- Database:      Supabase (PostgreSQL in the cloud)
- Auth:          Supabase Auth (email + password login)
- Styling:       Inline CSS + TailwindCSS
- File Exports:  XLSX library (Excel downloads)
- Maps:          Google Maps API (for location pinning)
- Hosting:       Runs locally on http://localhost:3000

PAGE 5: ADMIN SETUP (/dashboard/admin)
================================================================
This is the most detailed SETUP page. It has 2 sections:

SECTION A: COMPANY SETUP (7-step wizard)
Used to configure a company in the system.

Step 1 — GROUP:
  Enter the Group Name (e.g. "Sharma Group")
  A Group can contain multiple companies.
  Upload group logo (optional)

Step 2 — COMPANY:
  Name of Establishment, Employer/Director Name,
  Company Type (Pvt Ltd / LLP / OPC / NGO etc.),
  Industry (Manufacturing / IT / Retail / Healthcare etc.),
  PAN Number*, TAN Number*, CIN, Date of Incorporation
  Letterhead Setup:
    Header image or text (shown at top of HR letters)
    Footer image or text
    Live preview of letterhead
  Upload Certificate of Incorporation

Step 3 — LOCATIONS:
  Add all offices, factories, warehouses, branches.
  Each location needs:
    Name*, Type (Head Office/Factory/Branch/etc.)*,
    PIN Code, State*, District*, Full Address*,
    License/Registration Number (Factory Lic / S&E),
    Google Maps pin (for geo-fencing attendance),
    Registration Certificate upload
  Can upload bulk locations via Excel template.
  Each State+District auto-links PT and ESIC registrations.

Step 4 — TAX (GST):
  Add GST registrations (one per state where business operates)
  Each GST entry: GSTIN number, State, Certificate upload

Step 5 — LABOUR LAW:
  EPF (Employee Provident Fund):
    Registration number (format: MHBAN1234567000)
    Coverage: All Locations OR Specific locations (checkbox)
    Department address for filing
    EPF Certificate upload

  ESIC (Employee State Insurance):
    State + District specific registration
    Main code + Sub codes
    Covered locations auto-link based on state+district
    Department address for filing

  PT (Professional Tax):
    State + District level (covers all locations in same district)
    Applicable in only 22 states in India
    Registration number, certificate

  LWF (Labour Welfare Fund):
    Toggle on/off
    Select applicable states

Step 6 — BANK:
  Operating Account (for company expenses)
  Salary Account (for employee salary payments)
  Both: Bank Name, Account Number, IFSC, Account Type

Step 7 — LICENSE:
  Ezer HRMS subscription plan:
    Plan: Starter / Growth / Enterprise
    Max Employees, Max Locations
    Valid From / Valid Till dates
    Annual Cost, Billing Cycle

On completion → "Setup Complete!" success screen shows:
  Group → Company name | Auto Code | Location count | Plan

"+ Add Another Company" button to repeat for next company.

SECTION B: MASTER SETUP
Configures dropdown values used across the system.
Categories → Types → Values hierarchy.

Examples:
  Category: Employment → Types: Designation, Grade, Department
  Category: Payroll → Types: Allowances, Deductions
  Each Type has Values with optional color and parent linking.

Data stored in:
  master_categories, master_types, master_values tables

KEY CONCEPTS TO UNDERSTAND
================================================================

GROUP vs COMPANY:
  A "Group" is the parent entity (e.g. Sharma Group).
  A Group has multiple Companies (Sharma Sons, Sharma Petro).
  Each Company has multiple Locations.
  Employees belong to a specific Company + Location.

MRF vs QUICK HIRE:
  MRF (Full) = formal process for white-collar roles (CTC ≥6L).
    Needs HR review → MD approval before hiring.
  Quick Hire = fast process for blue-collar/shop floor workers.
    Site HR can directly approve. Only 5 fields to fill.

COLLAR TYPE:
  White Collar (WC) = office/management staff
  Blue Collar (BC) = factory/shop floor workers

EMPLOYMENT TYPE:
  Employee   = permanent full-time staff
  Intern     = temporary intern
  NAPS       = National Apprenticeship Promotion Scheme
               (government apprentice, lower cost to company)
  NATS       = National Apprenticeship Training Scheme
               (graduate trainee, similar to NAPS)
  Consultant = hired on contract/consultancy basis
  Contract   = contractual worker via contractor

STATUTORY COMPLIANCE (Indian Labour Law):
  PF  = Provident Fund — 12% employee + 12% employer
        mandatory for salary < ₹15,000/month
  ESIC = Employee State Insurance — medical insurance
         mandatory for salary < ₹21,000/month
  PT  = Professional Tax — state tax on salaried employees
        varies by state (max ₹2,500/year)
  LWF = Labour Welfare Fund — small monthly contribution
        applicable in select states only

HOW DATA FLOWS (End to End)
================================================================
1. Admin sets up Company + Locations + Registrations (Admin Setup)
2. HR raises MRF for a new position (Recruitment → Requisitions)
3. MRF gets approved by manager/MD
4. Job Opening is created and published (Recruitment → Jobs)
5. Candidates apply / are added manually (Recruitment → Pipeline)
6. Candidates move through interview stages in Kanban board
7. Selected candidate gets Offer (Offers tab — coming soon)
8. Candidate joins → Employee record created (Employee Master)
9. Employee goes through Onboarding (coming soon)
10. Monthly: Payroll processed, Compliance filings done (coming soon)
11. Employee self-service via ESS portal (coming soon)
12. Reports generated for management (coming soon)

HOW TO START THE APP
================================================================
Open terminal in the project folder and run:

  export NVM_DIR="$HOME/.nvm" && . "$NVM_DIR/nvm.sh"
  nvm use 22
  npm run dev -- --hostname 0.0.0.0

Then open: http://localhost:3000

The app will be accessible on your local network at:
  http://YOUR_LOCAL_IP:3000
  (e.g. http://192.168.100.139:3000 for mobile access)
